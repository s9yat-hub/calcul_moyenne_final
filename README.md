# calcul_moyenne_final
ceci est un projet regroupant plusieurs versions pour calculer une moyenne finzl

version1.py: les notes et les coefficients sont saisis au clavier 
version2.py: les notes et les coefficients sont dans des listes 
version3.py: les notes et les coefficients sont dans des dictionnaires 
version4.py: calcul avec `np.average` sur toutes les matières, graphique des résultats et décision du jury.
version5.py: interface graphique avec Tkinter.
